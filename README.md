# AI-Powered Personal Shopping Agent

An AI-powered shopping agent that understands user requirements,
compares products, and provides personalized recommendations.

## Problem Statement

Online shoppers often spend a lot of time searching through multiple
products and comparing prices, specifications, and features.

Our system uses AI to understand the user's requirements and provide
personalized product recommendations.

## Objectives

- Understand user requirements using natural language
- Extract important product preferences
- Compare products based on user requirements
- Provide personalized recommendations
- Explain why a product was recommended
- Reduce the time required for product discovery

## Key Features

- Natural language product search
- AI-based requirement analysis
- Product comparison
- Personalized recommendations
- Explainable recommendations
- Agent-based workflow
